## Appium automation

A small python script using Appium with its UiAutomator2 driver to automate phone calls on an Android device.

### About

This script explores Android UI automation using Appium with the UiAutomator2 driver. It uses ADB (Android Debug Bridge) to interact with and manage the connected Android device as part of the automation setup.

The primary objective was to automate the process of initiating phone calls on an Android device.


### Prerequisites

- Appium Server
- UiAutomator2 driver
- Android SDK Platform Tools (ADB)
- Android device with USB debugging enabled

### Purpose

A small hands-on project to explore mobile automation, Android device interaction, and automated call execution using Appium.
